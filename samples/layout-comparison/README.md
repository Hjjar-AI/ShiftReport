# Historical A5 layout comparison

These retained PDFs predate the fixed-column desktop alignment. The same six fictional sample patients in three layouts, with a filled follow-up on the first card (four filled/two empty follow-ups total): current stacked panels, lab groups in two columns, and all clinical sections in two columns. Demographics remain full width; each section uses its own content height. Read down the right column, then down the left, then continue on the next page. Diagnosis, treatment, follow-up, ordered lab groups and finally tasks retain their source order, with independent thin inset separators. No nested treatment/lab columns in the full two-column layout. Every page is marked DEMO.

Preview presentation includes current Android nominal body/heading/name sizes (12.5/13/16pt), normal-text-colored admission number beside its heading, no dashed team/admission separators, heavier dots and 12% theme-tinted section headings. Generated with the production desktop ReportLab renderer and bundled Tajawal font. Android uses Android Canvas/Paint and requires separate compilation/native PDF acceptance; these files do not establish pixel or pagination parity. No network/app/database access.

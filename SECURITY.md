# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/Hjjar-AI/ShiftReport/security/advisories/new) if enabled. Otherwise use a private contact explicitly published by [the maintainer](https://github.com/Hjjar-AI); do not open a public issue containing sensitive details. Private-reporting availability has not been verified.

Include affected versions, expected/observed behavior and sanitized reproduction steps. Never attach patient information, Telegram tokens or destination identifiers, PINs/passwords, protected joins, signing keys, clinical exports, databases or backups. No response-time commitment is implied.

Preserve existing clinical data, encryption and signing identity while investigating. See [project rules](AGENTS.md).

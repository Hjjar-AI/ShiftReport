# Earlier UI selections

The owner selected these Android/desktop presentation changes on 19 October 2026;
they are completed historical scope, not a second implementation backlog.

- Android: compact ward header/filter context; quieter cards retaining full clinical
  content; focused view options distinct from stored sorting; roster-first reviewed
  report flow with optional appearance; purpose-based settings; discoverable Save-next/round position.
- Desktop: slimmer sidebar/secondary tools; compact search/options/Add toolbar;
  quieter cards/action menus; one report workspace; stable patient widgets while filtering.
- A desktop split-pane redesign was not selected.

Current behavior and limits: [Android presentation](../current-state.md#shared-android-presentation)
and [desktop client](../current-state.md#standalone-desktop). New optional choices
are maintained in the [decision register](../decisions/android-ui-options.md).

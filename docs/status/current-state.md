## Security and recovery

Project creation presents numbered connection/admin/protection sections, explains a single group versus optional topics within it, and collapses optional residents routing with retained-value notices. Inline numeric-ID help and detailed private message-link examples guide manual configuration. Join accepts file selection and password in either order, with the file button above the password. Encryption is chosen at creation; reconnect validates project/key/topics and preserves records. Missing keys preserve files for recovery. PDFs are readable; secrets stay out of logs, saved UI and exports.

Telegram login uses a private six-digit code, memory-only salted hash, five-minute expiry and five attempts; no shared update-queue polling. Offline PIN entry requires device enrollment for the current linked identity/hash. Live admin/identity and privileged-account guards remain below UI. PIN cooldown is 5/15/60 minutes; default auto-lock is five minutes.
